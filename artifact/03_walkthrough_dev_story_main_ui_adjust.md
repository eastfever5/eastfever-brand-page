# DEV STORY 메인 노출 카드 3개 확장 및 UI 개선 완료 보고서 (03)

이 문서는 메인 페이지의 DEV STORY 영역 카드의 노출 개수를 3개로 늘리고, 카드 크기와 하단 링크 버튼을 웹앱 카드 디자인 규격에 맞추어 개선하고 검증을 완료한 내용을 담고 있습니다.

## 작업 상세 내용

### 1. 포스트 노출 개수 확장 (`src/components/HomePage.astro`)
- 메인 페이지에서 노출되는 최신 DEV STORY 포스트 수를 기존 2개에서 **3개**로 확장하였습니다.
- `latestPosts`를 정렬 후 `.slice(0, 3)` 하도록 수정하여, 최근에 추가된 `029`번 순위표 계산기 개발 후기를 포함한 3개의 최신 포스트가 메인 화면에 렌더링되게 만들었습니다.

### 2. 버튼 UI 교체 및 다국어 텍스트 최적화
- **중첩 링크 에러 방지**: 카드 전체가 상세 이동 링크(`<a>`)이므로, 내부에 또 다른 `<a>` 태그를 쓰면 발생하는 HTML 표준 마크업 위반 문제를 피하기 위해 버튼을 `<span class="visit-btn">` 태그로 마크업하였습니다.
- **다국어 리소스 수정** (`data/data.json`): `data.common.readStory` 값을 직접 수정하여 한글은 "상세 내용 보기", 영어는 "View Details", 일본어는 "詳細を見る" 로 번역 텍스트를 기입하였습니다. 이로써 다국어 처리의 관심사 분리(Separation of Concerns)를 달성하였습니다.

### 3. 레이아웃 규격 일치화 및 반응형 가로 스크롤 구현
- **데스크톱 그리드 통일** (`src/styles/global.css`):
  - `.devstory-grid`를 웹앱 그리드인 `.service-grid`와 동일하게 3열 형태(`grid-template-columns: repeat(auto-fit, minmax(300px, 1fr))`) 및 간격(`gap: 2rem`)으로 갱신하여 3개 카드가 화면 크기에 맞추어 자연스럽게 정렬되도록 만들었습니다.
- **모바일 반응형 가로 스크롤 구현** (`src/styles/mobile.css`):
  - 모바일(767px 이하) 화면에서 카드가 수직 누적되던 구조를 개선하고, 웹앱 그리드처럼 부드러운 가로 슬라이더 레이아웃(`display: flex`, `overflow-x: auto`, `scroll-snap-type: x mandatory`)을 적용하였습니다.
  - 카드의 폭을 `flex: 0 0 290px`로 동일화하여 손가락 터치 제스처 등으로 부드럽게 넘겨볼 수 있습니다.
- **호버 마이크로 인터랙션 추가**:
  - 카드 전체에 마우스가 호버되었을 때 하단 버튼 영역도 함께 반응형으로 색상(`#0284c7`)이 어두워지는 디테일(`.devstory-card:hover .visit-btn`)을 부여했습니다.
