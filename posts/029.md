---# 2026년 바이브코딩으로 만들어 본 순위표 생성기 feat. 점수.txt

최근 텍사스 홀덤 바를 다니게 됐는데

거기서 정리해 주는 주간/월간 점수표로

순위 리스트를 작성하는 앱을

간단하게 한 번 만들어 봤어요.

&nbsp;

만든 앱은 이미 배포까지 했어요.

아래 링크 박스를 클릭해 보세요.

::og-card{url="https://rank.eastfever.com/" title="Score Text Rank Calculator - RankBoard Maker" description="An intuitive web tool that generates sorted leaderboards and rank distributions based on percentiles when you enter a score list." image="/assets/blog/029/image-01.png"}

&nbsp;

데스크탑 화면 기준( 모바일도 지원해요! )

아래와 같이 좌측에 간략히 정리한

점수표를 붙여 넣으면 바로~

![네이버 블로그 이미지](/assets/blog/029/image-02.png)

아래와 같이 순위표를 뽑아 줍니다.

결과 순위는 이미지/텍스트로도

클립보드에 붙여서 다른 곳에

공유하기 쉽게 만들어 봤어요.

![네이버 블로그 이미지](/assets/blog/029/image-03.png)

---

처음 시작은 홀덤바에서

아래와 같이 점수표를 공유해 주길래

순위 계산을 하려다 제미나이한테

순위 계산을 부탁하다가요.

![네이버 블로그 이미지](/assets/blog/029/image-04.png)

이런 점수 계산을 자주 하게 될듯해

그냥 웹앱으로 만들어서 순위표 뽑자

그렇게 생각이 이어지더라구요.

&nbsp;

초기 아이디어를 바로 AI에게 전달하고

웹앱으로 구현 하는데에는

1시간도 안 걸린거 같네요

&nbsp;

![네이버 블로그 이미지](/assets/blog/029/image-05.png)

![네이버 블로그 이미지](/assets/blog/029/image-06.png)

하지만 복붙 기능이나,

점수표 오류 찾기/정정 기능 등등

편의 기능을 계속 추가하고

SEO나 다국어 지원도 챙기는 등

&nbsp;

일단 만들기 시작하니

이런저런 기능들을 계속 추가하게 되고

깨작깨작 만들다 보니

결국 2~3일 정도 걸린 것 같네요.

&nbsp;

제작에는 최근 2.0 업데이트를 완료한

Antigravity를 활용 하였구요.

사용 모델은 3.5flash(Medium)을 썼어요.

&nbsp;

배포는 제가 즐겨쓰는

Cloudflare Pages를 활용 했어요.

---

이렇게 해서 최근 간략히 만들어 본

웹앱 사례로서 "점수 순위 계산기"

제작 사례를 한 번 정리해 보았습니다.

&nbsp;

이렇게 AI를 개발에 활용하면

욕심 안 부리고 간략한 기능만 만들고 공유하는데

한나절이면 충분한 세상이 왔네요

&nbsp;

저도 매번 직접 만들고 돌려 보면서

이런 엄청난 생산성에

매번 혀를 내두르게 되네요

&nbsp;

앞으로 또 이렇게

생활속에서 활용하기 위해

앱을 간략히 만들고 배포하는 사례가

또 나오면 계속 내용 공유해 볼께요.
